## How This Portfolio Works
Each folder represents a full project scenario, built out with the same 
artifacts a real Project Manager would produce — from charter through 
closeout. The goal is to show not just PM terminology, but how I'd actually 
think through and manage a project end to end.

## Scenarios

### 🏥 [EHR System Rollout — Multi-Site Clinic Network](./scenario-01-ehr-rollout/)
Led a phased rollout of a unified cloud-based EHR platform across a 6-site 
healthcare clinic network, coordinating IT, clinical staff, and compliance 
under a state regulatory deadline.

**Artifacts:** Project Charter, RACI Matrix, Risk Register, Rollout Timeline, 
Training Plan, Communication Plan, Stakeholder Register, Go-Live Checklist, 
Lessons Learned, Post-Implementation Review

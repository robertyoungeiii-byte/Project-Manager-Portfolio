## Communication Matrix

| Audience | Method | Frequency | Owner | Purpose |
|----------|--------|-----------|-------|---------|
| Steering Committee (VP, IT Director, Compliance Officer) | Status meeting | Weekly | Project Manager | Review progress, risks, decisions needed |
| Clinic Site Directors | Email + biweekly call | Biweekly | Project Manager | Site-specific readiness updates |
| Clinical & Admin Staff | All-hands email + posted flyers | Monthly (weekly during go-live windows) | Project Manager + Site Directors | General awareness, training reminders |
| Super Users | Dedicated Slack channel | Ongoing/real-time | Project Manager | Quick Q&A, troubleshooting during go-live |
| EHR Vendor | Sync call | Weekly | Project Manager | Track configuration progress, blockers |
| Patients | Signage in clinics + patient portal notice | 2 weeks before each site go-live | Clinic Site Directors | Awareness of any temporary changes |

## Escalation Path
1. Staff-level issue → Super User
2. Unresolved → Site Director → Project Manager
3. Compliance-related issue → Compliance Officer (immediate, bypasses normal chain)
4. Technical/system issue → IT Director → Vendor

## Reporting Cadence
- **Weekly status report** to steering committee (progress, risks, upcoming milestones)
- **Go-live day**: real-time updates every 2 hours during cutover window
- **Post go-live**: daily check-ins for first 5 business days (hypercare period)

## Notes
- Communication frequency increased significantly during each site's 
  2-week pre-go-live window to reduce surprises
- A dedicated FAQ document, updated weekly, reduced repetitive questions 
  to the project team

# Go-Live Checklist — EHR System Rollout

> **Note:** This is a fictional case study created to demonstrate technical 
> project management skills. It is not based on a real employer, client, 
> or project.

## Purpose
Standardized checklist used before each site's go-live to confirm readiness 
across technical, staffing, and compliance dimensions. Applied at all 6 sites, 
with sign-off required from each listed owner before cutover proceeded.

## Pre-Go-Live (1 Week Before)

- [ ] Data migration validation completed and signed off — *IT Director*
- [ ] Final HIPAA compliance check completed — *Compliance Officer*
- [ ] All staff completed role-based training — *Site Director*
- [ ] Super users confirmed available for go-live week — *Site Director*
- [ ] Workflow dry-run / dress rehearsal completed — *Project Manager*
- [ ] Vendor support team confirmed on-site or on-call for go-live day — *EHR Vendor*
- [ ] Rollback/contingency plan reviewed and confirmed — *IT Director*
- [ ] Patient communication (signage, portal notice) posted — *Site Director*

## Go-Live Day

- [ ] Legacy system access frozen at scheduled cutoff time — *IT Director*
- [ ] Final data sync completed — *IT Director*
- [ ] New system access verified for all staff roles — *IT Director*
- [ ] Super users and vendor support present on-site — *Project Manager*
- [ ] First patient check-in/appointment processed successfully in new system — *Site Director*
- [ ] Real-time issue log opened for go-live day tracking — *Project Manager*

## Post-Go-Live (First 5 Business Days — Hypercare)

- [ ] Daily check-in with site staff — *Project Manager*
- [ ] Support ticket volume tracked against baseline threshold — *IT Director*
- [ ] Billing/claims processing verified functioning correctly — *IT Director*
- [ ] Staff confidence survey distributed — *Project Manager*
- [ ] Outstanding issues logged and prioritized — *Project Manager*
- [ ] Hypercare support wind-down confirmed once site is stable — *Site Director*

# RACI Matrix — EHR System Rollout

> **Note:** This is a fictional case study created to demonstrate technical
> project management skills. It is not based on a real employer, client,
> or project.

**R** = Responsible | **A** = Accountable | **C** = Consulted | **I** = Informed

| Task / Deliverable                  | Project Manager | VP Clinical Ops | IT Director | Compliance Officer | Clinic Site Directors | Clinical Staff | EHR Vendor |
|--------------------------------------|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| Project Charter Approval             | R   | A   | C   | C   | I   | I   | I   |
| Vendor Selection & Contract          | C   | A   | R   | C   | I   | I   | R   |
| Data Migration Plan                  | A   | I   | R   | C   | I   | I   | R   |
| HIPAA Compliance Review              | C   | I   | C   | A/R | I   | I   | C   |
| System Configuration                 | A   | I   | R   | C   | C   | C   | R   |
| Pilot Site Selection                 | R   | A   | C   | I   | C   | I   | I   |
| Staff Training Delivery              | A   | I   | C   | I   | R   | R   | C   |
| Go-Live Readiness Sign-off           | R   | A   | C   | C   | C   | I   | C   |
| Cutover Execution                    | A   | I   | R   | I   | C   | C   | R   |
| Post-Launch Support                  | A   | I   | R   | I   | C   | R   | R   |
| Post-Implementation Review           | R   | A   | C   | C   | C   | C   | I   |

## Notes
- Compliance Officer holds joint Accountable/Responsible status on HIPAA
  review given regulatory stakes
- Clinical Staff are Responsible for training completion and go-live
  participation but not accountable for project-level decisions
- Vendor is Responsible for technical execution items but never
  Accountable — accountability stays internal
